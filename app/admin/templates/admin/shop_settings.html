Настройки витрины магазина

После загрузки файл сразу применится к витрине и появится в списке выше.
💡 Как создать уникальный дизайн с помощью ИИ за 1 минуту
  1. Скопируйте готовый запрос (промпт) по кнопке ниже.
  2. Откройте любую нейросеть (ChatGPT, Claude, Gemini, DeepSeek и др.) и вставьте текст.
  3. В конце запроса опишите свой стиль (например: «тёмная киберпанк-тема с неоновыми акцентами» или «нежный пастельный стиль для кондитерской»).
  4. Скопируйте сгенерированный ИИ код, сохраните его в файл с расширением .css (например, my_theme.css) через Блокнот.
  5. Загрузите этот файл в поле выше и нажмите «Сохранить настройки».
Ты — Senior UI/UX-дизайнер и фронтенд-разработчик. К тебе обращается владелец интернет-магазина «{{ shop.name or 'Мой магазин' }}»{{ ' (' + shop.slogan + ')' if shop and shop.slogan else '' }}, чтобы создать единую визуальную тему (CSS-файл) для всей витрины на FastAPI + Jinja2.

ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ (ОБЯЗАТЕЛЬНО):
1. Первой строкой файла обязательно напиши:
   @import url("/store/static/default.css");
2. Если подключаешь шрифты (например, Google Fonts), добавь их @import сразу после импорта default.css.
3. Не ломай адаптивную сетку (flex/grid), видимость элементов с атрибутом [hidden] и читаемость текста (соблюдай контрастность фона и шрифта на всех экранах).
4. Выведи ТОЛЬКО чистый валидный CSS-код (без markdown-разметки ```css и без текстовых пояснений до или после кода), чтобы пользователь мог сразу сохранить ответ в файл theme.css.
