# Интернет-магазин на FastAPI + PostgreSQL

Готовый к запуску интернет-магазин с публичной витриной, корзиной, оформлением заказов, личным кабинетом, админ-панелью и поддержкой кастомных CSS-тем (включая генерацию дизайна с помощью нейросетей).

---

## Быстрый запуск за 3 шага

### 1. Что нужно установить
* **Docker Desktop** (для Windows / macOS) или **Docker Engine + Docker Compose** (для Linux).
* **Python 3.10+** (нужен один раз для запуска мастера настройки).

### 2. Скачивание и запуск
1. Скачайте репозиторий (кнопка **Code → Download ZIP** и распакуйте архив, либо через `git clone`).
2. Запустите **Docker Desktop** и дождитесь, пока он перейдёт в рабочий режим.
3. Откройте папку проекта и запустите мастер настройки:
   * **На Windows:** двойной клик по файлу **`start.bat`**
   * **На macOS / Linux (или через терминал):**
     ```bash
     python setup.py
     ```
4. В открывшемся окне нажимайте **Enter**, чтобы принять стандартные настройки для Docker:
   * Скрипт сам сгенерирует `SECRET_KEY`.
   * Создаст файл `.env`.
   * Соберёт и запустит контейнеры (`db`, `web`, `nginx`).

---

## Первый вход и настройка магазина

После запуска откройте в браузере:
* **Витрина магазина:** `http://127.0.0`
* **Панель управления:** `http://127.0.0admin`

### Данные администратора по умолчанию
При первом старте автоматически создаётся учётная запись администратора:
* **Email:** `admin@shop`
* **Пароль:** `admin12345`

1. Перейдите на страницу входа (`/login`) и авторизуйтесь под этими данными.
2. Откройте **Личный кабинет** (`/profile`), нажмите **«Редактировать»** и замените дефолтный `admin@shop.local` на свой email.
3. Перейдите в **Панель управления → Настройки магазина** (`/admin/shop-settings`), чтобы указать название бренда, слоган, описание «О магазине», телефон, адрес и график работы.

## Уникальный дизайн витрины за 1 минуту (через ИИ)

В админ-панели на странице **`/admin/shop-settings`** встроен готовый системный промпт со всеми CSS-переменными и классами витрины:
1. Раскройте блок **«Как создать уникальный дизайн с помощью ИИ за 1 минуту»**.
2. Нажмите **«Скопировать промпт для ИИ»**, вставьте его в любую нейросеть (ChatGPT, Claude, Gemini, DeepSeek) и допишите в конце пожелания по стилю и цветам.
3. Сохраните сгенерированный CSS-код в файл с расширением `.css` (например, `my_theme.css`).
4. Загрузите файл в поле **«Или загрузить свой .css файл»** и нажмите **«Сохранить настройки»** — тема применится ко всем страницам магазина.

## Управление проектом

* **Остановить контейнеры:** `docker compose down`
* **Запустить снова:** `docker compose up -d`
* **Посмотреть логи приложения:** `docker compose logs -f web`
