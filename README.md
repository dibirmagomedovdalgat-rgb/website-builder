## 🛠️ Инструкция по запуску

Для корректной работы приложения убедитесь, что у вас запущен Docker-контейнер с базой данных `postgres_db`.

### 1. Создание виртуального окружения
Создайте чистое изолированное окружение для проекта:
```bash
python -m venv .venv
```

### 2. Активация окружения
Активируйте созданное виртуальное окружение (команда для Windows):
```bash
.venv\Scripts\activate
```
*(Для macOS/Linux используйте команду: `source .venv/bin/activate`)*

### 3. Установка зависимостей
Установите все необходимые библиотеки из файла конфигурации:
```bash
pip install -r requirements.txt
```

### 4. Запуск сервера
Запустите сервер разработки Uvicorn с поддержкой автоматической перезагрузки кода:
```bash
uvicorn app.main:app --reload
```

## 🔑 Вход в панель администратора

По умолчанию новые пользователи регистрируются с обычной ролью. Чтобы получить доступ к панели администратора, выполните следующие шаги:

1. **Зарегистрируйтесь** в приложении через интерфейс или API под своим Email.
2. **Выдайте роль администратора** через терминал. Скопируйте команду ниже, заменив `'Ваш email'` на адрес, указанный при регистрации:

```bash
echo "UPDATE users SET role = 'admin' WHERE email = 'Ваш email';" | docker exec -i postgres_db sh -c 'psql -U "\(POSTGRES_USER" -d "\)POSTGRES_DB"'
```

После выполнения команды в консоли должно появиться сообщение `UPDATE 1`. Теперь вы можете войти в систему с правами администратора.
